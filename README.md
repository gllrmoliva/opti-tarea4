# Tarea4 Optimizacion
Tarea que consiste en implementar el modelo matemático que resuelve el problema de job shop flexible, propuesto por Fattahi et al. 2007. 

## Requisitos
- Utilizar versión 3.9 de python (se puede utilizar conda o pyenv)
- Tener instalado previamente gurobi optimizer con su respectiva licencia.
- Instalar librerias `gurobi, docplex, cplex, auto_dotenv`

## Ejecución
Dentro del directorio principal (\<DIR\>/opti-tarea4/) ejecutar:
``` bash
python script.py
```

> Instancias de problema obtenidas de: https://sites.google.com/site/atspinstances/tsp-lib-instances
