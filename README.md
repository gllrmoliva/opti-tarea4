# Optimización: Tarea 4

## Requisitos
Los requisitos necesarios son:
- Utilizar versión 3.13.7 de python (se puede utilizar conda o pyenv)
- Tener instalado previamente gurobi optimizer con su respectiva licencia.
- Instalar librerias necesarias con `pip install -r requirements.txt`

Además se debe crear un archivo `.env` con las siguientes variables:
```bash
GRB_WLSACCESSID=YOURTOKEN
GRB_WLSSECRET=YOURTOKEN
GRB_LICENSEID=YOURTOKEN
```

## Ejecución
Dentro del directorio principal (\<DIR\>/opti-tarea4/) ejecutar:
``` bash
python main.py
```

> Dataset: https://www.kaggle.com/datasets/ziya07/traveling-salesman-problem-tsplib-dataset
